FAQ

Where does ChemFYI source periodic table data?

ChemFYI sources IUPAC + NIST. 118 elements with atomic number, mass, electron config, ionization, melting/boiling points, electronegativity, isotopes. Compounds via CAS Registry. Balanced reactions.

What alloy properties does AlloyFYI document?

AlloyFYI documents 100+ alloys: steels (carbon/stainless/tool/HSLA), aluminum (1xxx-7xxx), brass, bronze, titanium, superalloys (Inconel, Hastelloy). Tensile/yield strength, hardness (Brinell/Rockwell/Vickers).

How are gemstones classified?

GemFYI uses GIA + IGS standards. 1,800+ gemstones with Mohs hardness, refractive index, specific gravity, crystal system, dispersion. Diamond 4Cs, pearl grading, opal types. Gemology glossary.

Which star catalogs does StarFYI integrate?

StarFYI uses Hipparcos/Tycho/Gaia DR3. 100K+ stars with apparent/absolute magnitude, spectral class (OBAFGKM), parallax distance. Exoplanets via NASA Exoplanet Archive. 88 IAU constellations.

Why 6,215 minerals in MineralFYI?

Per the IMA (International Mineralogical Association) current list. MineralFYI has chemical formula, crystal system, Mohs hardness, density, cleavage, luster, color, locality per mineral. Dana classification + Nickel-Strunz cross-references.
